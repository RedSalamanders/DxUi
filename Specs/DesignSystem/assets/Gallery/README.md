Control gallery sheets rendered by DxUi's own test harness (`gallery.ps1 -PublishDocs`) from the compiled controls, with reduced motion and deterministic scenarios; never desktop screenshots. One sheet per theme: Light, Dark, Rainbow light, Rainbow dark and High contrast, each covering all 30 public controls and their interaction variants on a 1600 DIP canvas. `embedded-controls.png` is the supplied-device (EmbeddedHost) sample. Use them as the authoritative rendering when a static preview differs; rendering may vary with installed Windows fonts and DPI.
