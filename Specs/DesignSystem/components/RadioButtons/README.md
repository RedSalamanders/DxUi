# RadioButtons

Group of mutually exclusive RadioButton choices with a header.

- **Consumer supplies**: choices, `SetHeader`, `SetSelectedIndex` and `SetOnSelectionChanged(int)`.
- **Type**: header in `BodyStrong`; choices in `Body`. Arrow keys move the selection within the group.

The preview is a static HTML rendition styled by `bundle.css` from the tokens; the real control is painted by DxUi.lib with Direct2D. The gallery captures under Assets › Gallery are the authoritative rendering.
