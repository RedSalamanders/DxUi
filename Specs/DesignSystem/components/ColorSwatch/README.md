# ColorSwatch

Clickable color chip that launches the consumer's color flow (for example ColorPicker).

- **Consumer supplies**: the displayed color and `SetOnClick`.
- **Metrics**: outer radius 4 (`radius-sm`), inner radius 2.5, 1 DIP `borderDefault` frame.

The preview is a static HTML rendition styled by `bundle.css` from the tokens; the real control is painted by DxUi.lib with Direct2D. The gallery captures under Assets › Gallery are the authoritative rendering.
