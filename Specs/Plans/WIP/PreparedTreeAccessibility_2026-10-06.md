## Ownership and compatibility requirements

An optional prepared source must be immutable and complete for the current model epoch, including stable item IDs, text, depth and expansion state. Retaining it is constant-size; it keeps all referenced text valid through concurrent provider reads and snapshot replacement. The consumer prepares, admits and retires its complete source graph. DxUi must not acquire an application document, scheduler or worker. Do not call a retired model from a published provider and do not choose a newer source merely because its row count or IDs match.

Legacy models keep the original snapshot path. All row navigation, provider properties and selected-item resolution use one coherent source. Failed or absent optional preparation has explicit fallback/refusal semantics; it never publishes half a source. Reentrant publication/disconnection retains the source and current provider target before callbacks. Hidden/suspended/replaced trees retain existing `UIA_E_ELEMENTNOTAVAILABLE` behavior.

No change to presentation, blend math, gallery pixels, focus ownership or consumer pins is implied. Review the documentation contract; this API change needs public usage documentation and semantic tests, with no new visual artifact unless rendering changes.
