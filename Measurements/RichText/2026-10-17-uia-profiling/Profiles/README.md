# Fixed diagnostic profiles

See the [study explanation](../README.md) for the eight-process schedule,
identity matching, CPU/cache/heap observations, images and observer limits.
Stamped benchmark reports retain `.json`; raw native reports, child metadata,
plan and completion JSON use `.receipt.txt` archive names. Their original bytes
and embedded original paths remain unchanged. The replay resolves archive names
and verifies every original hash, native field and artifact identity.
