# Next retained-line investigation (design only)

Do not install any draft before the current 14-operation diagnostic matrix,
explicit Release timing and fixed four-policy controls finish and are archived.

1. Add a bounded independent DirectWrite callback recorder to the existing
   document-layout native test. Compare actual whole-layout callback baselines,
   line metrics, ACP geometry and height with float-by-float and double prefix
   sums at 13, 18 and 18.1 DIP, wrapped/mixed-font/RTL text and the 65,536-newline
   boundary. Do not assume current fallback predicates reveal DirectWrite's
   internal accumulation. Keep each original discrepancy and artifact.
2. Use explicit per-visual-line local and global placements for chunk queries.
   Correct carets, ranges, visible ranges and hit-test coordinate conversion;
   exclude only nonfinal phantom LF lines. Independent whole-layout oracles stay.
3. Investigate a public IDWriteTextRenderer callback adapter for exact global run
   baselines. Glyph description source positions can identify visual lines more
   reliably than equality of rounded local baseline floats. Different run/font
   baseline adjustments, decoration runs, pixel snapping, world transform/origin
   association and color fonts all need independent emitted-run and pixel proof.
4. Preserve ENABLE_COLOR_FONT behavior. SDK Factory4/8 color enumeration and
   DeviceContext4/7 bitmap/SVG/paint APIs have capability and format distinctions;
   monochrome-only DrawGlyphRun is not an acceptable universal replacement.
   Retain canonical fallback until every claimed path passes exact pixels.
5. Bound all line/run indexes, keep preparation on host owner, no embedded-owned
   worker/timer/device. Cached composition must remain allocation free. New
   preparation failures retain the previous source/geometry pair atomically.
6. Only after affected checks pass, rerun the unchanged explicit real-host trial
   to bind actual prepared/reused/whole-layout work and timings. Faster rejected
   geometry/pixels never count as an optimization.
