# Unicode rich-text feature laboratory

An editable tour of our own C++ control. Press F6 to switch between formatted and exact Markdown source. File > Save as writes UTF-8; keep this original as a reusable test document.

## What you can test today

The current formatted preview supports headings, **bold**, *italic*, `inline code`, ~~strikeout~~ and nested **bold with *italic* inside**. Select text and try Ctrl+B, Ctrl+I, Format > Code, Ctrl+Z and Ctrl+Y. Resize this window to test wrapping. Select across paragraphs, drag backwards, use Shift+arrows, Home/End and the mouse wheel.

The later sections deliberately include syntax awaiting the new semantic renderer. Its markers remain editable source in this application. A parsed feature is not yet a rendered or structurally editable feature. Math, diagrams, footnotes and front matter also await their dedicated implementation.

### Editing and source preservation

1. Put the caret inside **this bold phrase** and type a Unicode character.
2. Undo, redo, then press F6 twice. Check that the source is unchanged.
3. Select only part of a styled phrase and apply another style.
4. Toggle View > Read-only. Selection and copying should work; typing should not change text.
5. Save a copy, reopen it, and compare the source. RTF and HTML clipboard output remain pending.

### Unicode and bidirectional text

Latin: café, naïve, Straße, Ελληνικά, русский, 日本語, 中文, 한국어.

Combining marks: é, Å, ñ. Supplementary scalars: 😀 𝄞 𐐀. Emoji clusters: 👨‍👩‍👧‍👦 👩🏽‍💻 🇫🇷 ❤️.

Mixed Hebrew and English: שלום — edit this English phrase — עולם 123.
Mixed Arabic and English: مرحبا — Unicode editor — بالعالم 456.

Try selecting and deleting around combining marks and emoji, then undo. Logical UTF-16 source positions and visual glyph positions differ; physical IME and assistive-technology acceptance remain separate qualification gates.

## Manual tour checklist

- Formatted/source switching preserves text and history.
- Source selection, typing, formatting, undo and redo work.
- Read-only blocks mutations while allowing selection and copy.
- Resizing, scrolling and Unicode hit testing remain usable.
- Saving/reopening preserves UTF-8 content.
- Unsupported syntax is visibly retained; images, scripts and links never load themselves.
- Complete Markdown rendering, structural edits, math/diagrams and physical AT/IME qualification remain pending.
