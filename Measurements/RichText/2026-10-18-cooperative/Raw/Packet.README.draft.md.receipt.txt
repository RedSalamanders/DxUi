# Cooperative Unicode rich-text preparation

Status: draft until final native/build/tooling qualification and sealed replay.
This record belongs to the owned DxUi control. The separately launched
RichEditRebuild demo uses its existing consumer pin; it is not evidence for this
new host implementation or an implicit consumer update.

The control advances geometry through shared owner turns rather than preparing
from input, painting or geometry queries. Each visible owner is limited to four
SDK layouts and 4,096 block/placement steps in a turn. One pending request
coalesces identical keys; source/mode/binding/width/typography/resource replacement
retires obsolete work. Cancellation releases staging without heap allocation.
Only complete source/geometry can publish; host text-service/UIA geometry follows
successful rasterization/presentation. One application notification is separate
from dirty pixels, and failed work does not request an automatic retry loop.

Source editing/history/IME remain available while geometry is pending. Visual
navigation, hit-testing, scrolling and current text bounds wait for prepared
geometry. Held embedded UIA providers retain their acknowledged snapshot text;
range bounds never combine it with a different live source/projection. Native
window hide and zero-size transitions explicitly cancel content while retaining
the existing native swap-chain/WM_SETREDRAW policy. Embedded views acquire no
worker, timer, renderer HWND, device or swap chain.

Projection/index construction, source-only logical navigation, joins, one long
physical paragraph and whole compatibility SDK calls remain indivisible v0
work. Work-unit limits are not hard millisecond guarantees. Complete Markdown,
semantic anchors/transactions, accepted extensions, source-visible pending/error
presentation, long-paragraph virtualization and large-document qualification
remain in the active plan. Physical IME/AT, agreed desktop-focus tests, native
ARM64 execution, consumer adoption and the original frame-performance HOLD are
also separate. No benchmark input, judge, threshold, tolerance or baseline changes.
