# Diagram note and caption resources

The [retained comparison](counterfactual.json) runs the same compiled fixture with
the retained baseline SDK and with five candidate translation units. The note
fixture reproduces a route crossing a note before the fix and passes final collision
invariants afterward, including ordinary notes that remain admitted. A collision
refuses publication and preserves exact editable source.

The 48-node Cartesian fixture contains 512 independent edges. Actual intercepted
DirectWrite calls fall from 512 matching captions / 560 total layouts to one
matching caption / 49 total layouts. Separate statements with the same styled
caption share; a different style remains distinct. Original source, executables,
PDBs, shared fixture object and logs are archived with every member verified.

This focused patch-object comparison does not establish complete current-SDK,
native ARM64, consumer, physical-input or formal paired-performance qualification.
