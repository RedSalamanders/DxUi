# Raw receipt filenames

Canonical Performance JSON keeps its original filename. Every other raw JSON is renamed to .receipt.txt with byte content unchanged.

- `Accessibility-receipt.json` -> `raw/Accessibility-receipt.receipt.txt`
- `Embedded-receipt.json` -> `raw/Embedded-receipt.receipt.txt`
- `Grid-receipt.json` -> `raw/Grid-receipt.receipt.txt`
- `inputs.json` -> `raw/inputs.receipt.txt`
- `Rendering-receipt.json` -> `raw/Rendering-receipt.receipt.txt`
