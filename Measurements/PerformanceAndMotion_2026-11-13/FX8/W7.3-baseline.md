# FX8: v0 chunk baseline for W7.3

Hand-written summary of the FX8 receipts in this directory (the generated [README](README.md) lists every receipt); the
numbers come from the `rich.chunksLaid` and `rich.wholeLayoutsLaid` series of those receipts, WARP, x64 Release. Each FX8
step is one action with every owner turn of preparation it causes (`Definition::settlePreparation`).

The default FX8 presentation (Rich mode, Markdown rendering, Subtle) is laid out by semantic geometry and lays no v0
chunks: `chunksLaid` is 0 for every action in `fx8-default` and `fx8-full`, so it says nothing about W7.3. The v0 document
layout (`PreparedDocumentLayout`, `src/Controls/DxUi.RichDocumentLayout.cpp`) runs only when the editor has no semantic
document, which the two added variant pairs reach:

| Variant | Configuration | Chunks laid per insert | Chunks laid per Enter | Chunks laid per resize step | Whole layouts per insert / Enter / resize step |
| --- | --- | --- | --- | --- | --- |
| `source` (7,936 units) | `ViewMode::Source` | 1-2 | 8-10 | 8 | 0 / 0 / 0 |
| `source-full` (65,280 units) | `ViewMode::Source` | 1-2 | 62-64 | 61 | 0 / 0 / 0 |
| `multiplier` (7,936 units) | Rich mode, Markdown rendering off, `lineHeightMultiplier` 1.5 | 0 | 0 | 0 | 1 / 1 / 1 |
| `multiplier-full` (65,280 units) | Rich mode, Markdown rendering off, `lineHeightMultiplier` 1.5 | 0 | 0 | 0 | 1 / 1 / 1 |

Inserts are the prose, fence and table-adjacent insert phases (identical ranges). Arrow keys and seeks lay out nothing.
In Source mode an insert re-lays the edited chunk (and one neighbour), while an Enter re-lays every chunk after the edit
because chunks bake their absolute vertical origin: 62-64 chunks of the full document per Enter (16 owner turns). With
the multiplier outside Source the v0 layout skips chunks and builds one whole-document layout per keystroke (56-59 owner
turns at full size). W7.3's gate ("chunks re-laid per insert <= 2 and per Enter <= 2") is measured against `source-full`;
its multiplier clause against `multiplier-full`, where the target is chunks instead of a whole layout.
